✨ Features Overview

🎬 Real-time Live Caption

  • Video Player: เล่นวิดีโอพร้อมแสดง Close Caption แบบ real-time
  • Chunk Display: แสดงข้อความแบ่งตาม timeline (1 ช่อง = 1 chunk)
  • Synchronized Playback: Close Caption แสดงตามจังหวะวิดีโอ
  • Visual Indicators: สีต่างกันสำหรับ chunk ปัจจุบัน/ผ่านแล้ว/ยังไม่ถึง

🔍 Search & History

  • Text Search: ค้นหาข้อความในวิดีโอที่แปลงแล้ว
  • Timestamp Results: แสดงผลการค้นหาพร้อม timestamp
  • History Management: ดูประวัติการแปลงเสียงทั้งหมด
  • Auto Search Test: ทดสอบค้นหาด้วยคำสุ่ม

📺 Live Caption

  • Real-time Updates: แสดงความคืบหน้าการแปลงเสียงแบบ real-time
  • WebSocket Support: ใช้ WebSocket สำหรับการอัปเดตแบบ real-time
  • Polling Fallback: ใช้ polling เป็น fallback เมื่อ WebSocket ไม่พร้อมใช้งาน

🚀 Quick Start Guide

  1. เลือก Environment: คลิกปุ่ม Local หรือ Staging ด้านบน
  2. เปิด Complete Test Suite: คลิก "เปิด Local Test" หรือ "เปิด Staging Test"
  3. อัปโหลดไฟล์: เลือกไฟล์ MP4, MP3, WAV, หรือ M4A
  4. ทดสอบฟีเจอร์:
    • 🚀 เริ่มแปลงเสียง - แปลงไฟล์เป็นข้อความ
    • 📺 Live Caption - แสดงความคืบหน้าการแปลง
    • 🎬 Real-time Live Caption - เล่นวิดีโอพร้อม Close Caption
    • 🔍 ทดสอบค้นหา - ค้นหาข้อความในวิดีโอ
